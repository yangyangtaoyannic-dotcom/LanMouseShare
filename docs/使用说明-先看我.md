# LanMouseShare 0.2.0-beta-fix6 使用说明

这是一个局域网内两台 Windows 电脑共享鼠标、键盘、剪贴板和文件传输的小工具。

## 适合谁用

- 两台 Windows 电脑在同一个局域网。
- 想用一套鼠标键盘在两台电脑之间切换。
- 想在两台电脑之间拖文件发送。
- 出问题时想在一台电脑上看到两台电脑的日志。

## 安装前准备

- 两台电脑都需要安装。
- 建议 Windows 10 或 Windows 7 SP1。
- 需要 .NET Framework 4.8。
- 安装时需要管理员权限。

## 快速安装

1. 在电脑 A 上右键运行：

   ```text
   LanMouseShareSetup.exe
   ```

   选择“以管理员身份运行”。

2. 在电脑 B 上也运行同一个安装器。

3. 两台电脑都打开 LanMouseShare 窗口。

4. 等待自动发现对方电脑。

5. 如果没有自动发现，就在其中一台电脑里手动输入另一台电脑的 IPv4 地址。

6. 发起配对，并在另一台电脑上同意。

7. 设置屏幕方向：

   - 如果电脑 B 在电脑 A 右边，就在电脑 A 上选“对端在右”。
   - 如果电脑 B 在电脑 A 左边，就选“对端在左”。
   - 上下方向同理。

8. 把鼠标移动到对应屏幕边缘，就可以跨屏控制。

## 常用功能

### 鼠标跨屏

鼠标碰到你设置方向的屏幕边缘，并继续往外移动，就会切换到另一台电脑。

### 键盘输入

当前鼠标控制哪台电脑，两边键盘都应该输入到哪台电脑。

### 文件传输

把文件拖到 LanMouseShare 窗口里即可发送。对方电脑收到后会保存到桌面：

```text
Mouse传输文件
```

### 剪贴板

默认支持文字和图片剪贴板同步，可以在界面里关闭。

## 0.1.47 版本变化

- 修掉“鼠标用着用着突然被丢回主控端”：以前被控端只要发现“注入后指针没动”就当成注入失败并交出控制权，而指针贴在屏幕边缘时本来就不会动，于是频繁误判。现在只记日志、不再交出控制权。
- 边缘返回改成“真的往外推才返回”：需要在 250 毫秒内累计向外推 12 像素以上才把控制权交回主控端，单次抖动或停在边缘不会触发，触发后还有 500 毫秒冷却。
- 远程指针改为绝对坐标注入：指针在远端屏幕上 1:1 跟随，不再出现越走越慢、飘移、到不了屏幕最右边的问题。
- 键盘互通加固：控制权结束、暂停、掉线时会自动补发抬起事件，不会出现 Ctrl/Shift 按着切回来导致本机键盘“粘住”；新增 `key.forward` / `key.inject` 日志，可以逐键核对两端。
- 日志降噪：每 2 秒一条的管道状态日志改为 DEBUG，不再刷满 INFO。
- 建议两台电脑都升级到 0.1.47，且两台版本必须一致。

## 0.1.46 版本变化

- 修复 0.1.45 在新环境里“完全切不过去”的问题：如果 Windows 防火墙挡掉了两个 Agent 之间的 UDP 47534，租约和确认现在会自动改走已经配对好的服务通道（Agent → 本机服务 → 对端服务 → 对端 Agent），不需要再手动加防火墙规则。
- 两条通道语义完全一致，重复或迟到的消息按世代号自动丢弃；切换稳定性不变，最坏情况仍然是 1 秒内回到本地键鼠。
- 新增日志事件：`control.lease.relay.fail`、`control.ack.relay.fail`、`control.lease.relay.parse.fail`、`control.ack.relay.parse.fail`；`control.link.arbitrated` 里会带 `path=udp` 或 `path=relay`，可以直接看出实际走的是哪条通道。
- 建议两台电脑都升级到 0.1.47，且两台版本必须一致。

## 0.1.45 版本变化

- 控制权改成“租约”机制：主控端每 50 毫秒续一次约，被控端 600 毫秒收不到就走回空闲，主控端 700 毫秒收不到确认就松开本机键鼠。任何一侧掉线、崩溃、拔网线，另一边都会在 1 秒内恢复本地键鼠，不会再出现两端一起卡死。
- 被控端永远不会把自己变成主控端：光标推到自己屏幕边缘只发“请求放开”，由主控端决定什么时候把光标放回来。
- 两端几乎同时切屏时用世代号（epoch）+ 设备号裁决，必然收敛成唯一主控端，不再互相抢。
- 新增日志事件：`control.link.role`、`control.link.begin`、`control.link.lease`、`control.link.released`、`control.link.timeout`、`control.link.arbitrated`、`control.link.stale`，只看日志就能还原每一次状态迁移。
- 完整规范见 `Docs\CONTROL-STATE-MODEL.md`（主控/被控端状态关系书）。
- 建议两台电脑都升级到同一版本（当前为 0.1.47），版本不一致时配对和边缘切换行为可能对不上。
- 万一还遇到卡住，按 `Ctrl+F10`（停止控制）或 `Ctrl+F11`（暂停）立刻恢复。

## 调试日志（0.1.43 新增）

想把两台电脑的日志汇总到一台机器上看，按下面做：

1. 在被控的那台电脑上，打开界面里的“调试日志”区域，角色选“被控端”。
2. 在“主控端地址”里填另一台电脑的 IP 和端口，例如：

   ```text
   192.168.1.20:47540
   ```

   留空也可以，程序会自动使用已发现或已配对的电脑地址。

3. 在另一台电脑上，角色选“主控端”。
4. 两端都点保存，看到“日志推送：已连接”就说明通了。
5. 需要更细的记录时勾选“详细日志”，排查完记得取消勾选。

日志文件位置：

```text
%ProgramData%\LanMouseShare\Logs\live    本机日志
%ProgramData%\LanMouseShare\Logs\remote  被控端汇总过来的日志
```

日志默认保留 3 天，可以在界面里改成 1 到 30 天。日志传输用 TCP `47540`，安装器已经自动配置防火墙。

## 快捷键

| 功能 | 默认快捷键 |
| --- | --- |
| 暂停/恢复跨屏 | `Ctrl+F11` |
| 停止所有控制 | `Ctrl+F10` |
| 关闭程序 | `Ctrl+Alt+End` |

快捷键可以在软件界面里修改。

## 如果装过旧版本或新版本

如果安装时出现奇怪问题，比如：

- 打开旧安装器却跳到新版本。
- 服务启动失败。
- 配对状态异常。
- 鼠标键盘状态不对。

先运行：

```text
LanMouseShare-Rollback-Clean.bat
```

它会自动请求管理员权限，并清理旧服务、旧安装目录、旧自启动和旧配置。清理完之后，再重新运行 `LanMouseShareSetup.exe`。

## 注意事项

- 两台电脑必须装同一个版本，不要混用不同版本的 Agent 和 Service。
- 向日葵、Mouse without Borders、远程桌面、投屏软件这类工具可能会拦截模拟鼠标输入，不保证能被稳定控制。
- 如果鼠标状态异常，优先按 `Ctrl+F10` 停止控制。
- 如果仍然异常，退出两端软件后运行回退清理工具，再重新安装。

## 0.1.50 版本变化

- 跨屏输入更省带宽：鼠标移动使用紧凑帧（相对移动 2 字节/次、绝对定位 4 字节/次），比旧版小一个数量级。
- 交互优先：鼠标键盘流量打 DSCP 46（EF），日志流量打 DSCP 8 并在你操作鼠标时自动降速，跨屏时不再因为传日志发涩。
- 日志推送可以关：Agent 窗口“调试日志”里有“推送日志到主控端”，关掉后日志只留本机。
- 文件可以直接复制粘贴：一台电脑上 Ctrl+C 复制文件，切到另一台 Ctrl+V 即可；文件在公共桌面 `Mouse传输文件` 目录，粘贴前会自动放进剪贴板。
- 主控端状态栏显示实测网络延时，方便判断卡顿是链路还是注入问题。
- 接收目录改为 `C:\Users\Public\Desktop\Mouse传输文件`（服务以 SYSTEM 运行，用户桌面路径它看不到）。

## 0.1.56 版本变化

- 复制文件/文件夹后**到对端粘贴才传输**，不再自动整包发送。
- 文件夹会先压成 zip 再传，对端解压出原文件夹，可直接粘贴。
